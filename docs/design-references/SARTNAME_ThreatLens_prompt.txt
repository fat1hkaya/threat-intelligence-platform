Aynı normalleştirilmiş IOC, aynı tür altında tekrar eklenmemeli.

IP, domain, URL ve hash değerlerinin normalleştirme kurallarını ayrı uygulama katmanında tanımla.
3.2 SQL Server Graph
SQL Server'ın gerçek AS NODE ve AS EDGE yapılarını kullan.

Düğümler:
- IOCNode

Kenarlar:

- ConfidenceScore

- EvidenceId
- FirstObserved
- LastObserved
alanları bulunmalı.

SQL Graph yön ilişkilerini açıkça tasarla. Uygun edge constraint kullanımı değerlendirilsin.

Tüm graf ilişkileri veri tabanında saklanmalı; frontend üzerinde rastgele bağlantılar üretilmemeli.

Graph tablolarının dahili $node_id, $edge_id, $from_id ve $to_id alanlarıyla çalışma mantığını doğru uygula.

Graph verisinin ilişkisel ana kayıtlarla tutarlılığını transaction ve doğrulama mantığıyla koru.
3.3 Veritabanı dersi gereksinimleri
Aşağıdakiler yalnızca raporda açıklanmayacak, gerçekten uygulanacak:

- Views

- GRANT ve DENY

- Backup ve restore senaryosu
- SQL Graph MATCH sorguları
